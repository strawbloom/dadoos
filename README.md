# Dadoos

A simple dice rolling app built with Flutter.

Tap the dice or the button to roll two dice with random values.

## Project Structure

```
lib/
├── main.dart            - Entry point
├── app.dart             - App configuration and theme
├── models/
│   └── dice.dart        - Dice logic and state
└── screens/
    └── home_screen.dart - Home screen UI
```

## Getting Started

```
flutter pub get
flutter run
```

## Built With

- Flutter
- Google Fonts
